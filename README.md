# Jarvis Desktop Assistant

A local AI-powered desktop assistant built with Python.

## Features

- Wake word activation ("Jarvis")
- Speech-to-Text
- Text-to-Speech
- App launching
- File creation, deletion, renaming
- System monitoring
- RAM, CPU, Battery information
- Memory-based commands
- Transparent animated GUI
- Sleep / Wake mode

## Tech Stack

- Python
- Ollama
- Qwen 3 8B
- PyQt6
- SpeechRecognition
- Edge TTS
- psutil

## Run

```bash
pip install -r requirements.txt
python main.py
